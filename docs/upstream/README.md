# Upstream reports

Reports of defects found in the projects this repository builds on, written so they can be filed as they are:
what was run, with which pinned versions, what happened, what was expected, where in the upstream source it
goes wrong, and what this repository does meanwhile. One file per report, named `YYYY-MM-DD-<project>-<what>.md`,
with its status at the top (not filed, filed with the link, fixed upstream in which version). When one is fixed
upstream, note the version here and keep the file.

A report is not a gap: the gap it causes stays in the component's own inventory (`experiments/paramdoc/GAPS.md`
for paramdoc) and points here.
