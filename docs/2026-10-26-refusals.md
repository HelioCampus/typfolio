# Refusals: what the paramdoc runtimes cannot reproduce stops with a message (M12)

Same experiment as `2026-10-26-addresses-and-links.md` (`experiments/paramdoc`): a browser runtime fills holes
in a document Typst laid out once. This note records the decision taken on 2026-10-26 and the work it led to.
`experiments/paramdoc/PLAN.md` (M12) has the plan as built; `GAPS.md` there is the inventory.

## The decision

The runtimes will not grow to cover everything. What would make the TypeScript runtime heavy stays out until a
better route exists: a shaper, bidi, hyphenation pattern tables, Unicode tables, an SVG renderer. Until then,
unsupported input stops with a message. It is never laid out differently from Typst, because the compiler is the
fallback for that document. Two gates and one proof: at export the template is checked against what the runtimes
are proven on, with the element, the reason and the fix in the message; at fill the data is checked only by
lookups the runtime makes anyway (the character map, the value's shape, an image header), so the runtimes gain
no tables. Hyphenation (G2) is not supported unless it comes without pattern tables; `hyphenate: false` stays
pinned inside slots.

## What was built

- **A character whitelist at export.** A slot's `charset` may declare the default set (printable ASCII, Latin-1,
  common typography, minus the soft hyphen and the middle dot), Latin Extended-A, -B and Additional, Greek and
  Coptic, Cyrillic and its Supplement, a few General Punctuation entries and the currency symbols. Everything
  else is refused with the reason: a script that needs a shaper, an East Asian character, a combining mark, a
  format or bidi control, a variation selector, an emoji, private use, a control character. A declared
  character the font lacks is an error naming the font (it used to be dropped, and the fill later blamed the
  repertoire). The whitelist names candidates; the proofs below admit them.
- **The shaping check, on every compile.** In the exporter's frame walk, every glyph Typst drew inside a slot
  must be the character map's glyph for exactly one character, at the font's horizontal advance with no offset,
  and every run of a slot must share the first run's font, size and colour. A space may be narrower than the
  font's advance: Typst keeps trailing spaces in the run at zero width and shrinks spaces by up to a third on an
  overfull line, and the runtimes port both. Anything else (`tnum`, `smcp`, `locl` under the template's
  language, `tracking`, `spacing`, a `show` rule recolouring digits) is refused with the glyph ids. Stroked text
  is refused everywhere, and so is a font with colour glyph tables (COLR, CBDT, sbix, SVG) or variation axes.
- **The repertoire proof, on every export.** The exporter fills each text slot with its whole repertoire (a
  space every eight characters so it wraps) through the real template, one extra compile with the template's
  fonts, language and rules, and the shaping check above runs on it; a character that does not come out is
  reported. Slots the data gives no value to (page counters, a slot sharing a number with a bar) are checked on
  their sample only, and the export says which.
- **The fuzz draws from each slot's own repertoire** instead of a fixed alphabet, so random texts of every
  admitted character are compared with Typst's layout. The old alphabet had no accented letter, no no-break
  space and none of `#&*<=>@[]^_{|}~`.
- **Pins in the dialect.** Inside slots `dir: ltr`, `tracking: 0pt`, `spacing: 100%`, `stroke: none` and
  `cjk-latin-spacing: none` join the pinned `kerning`, `ligatures`, `calt`, `overhang`, `bottom-edge` and
  `hyphenate`, so a template's own `set text` rules cannot reach a slot's text.
- **Refusals that were warnings.** A single-line sample that wrapped, a baseline off the contract, a baseline
  off the line grid and a sample taller than its box used to be printed and exported; they stop the export now.
  A `lines: auto` sample whose measured line count is not what Typst laid out is refused too (a rounding tie).
- **Geometry.** A `clip` or `ellipsis` wrapping slot whose repertoire's tallest glyph rises more than
  `pitch − descent` above the baseline is refused: Typst's clipped box would show the top of the first dropped
  line and the runtimes, which drop whole lines, would not.
- **Images and links.** `image(scaling: "smooth")` is refused at export (the runtimes do not write the
  interpolation flag); a rotated or skewed static link is refused at export (its clickable area would be a
  bounding box, not Typst's quadrilateral); a JPEG whose EXIF orientation tag is not 1 is refused at fill, in
  both runtimes, with the message to rotate it before sending; a link slot under the `shrink` policy now shrinks
  its clickable rectangle with the text.
- **Values.** A number with a fraction is refused at fill: Typst's `str()` and the runtimes' number formatting
  agree on integers and booleans, which the fuzz proves, not on every float. Soft hyphens in data get their own
  message.

## What the proof found

Running the fuzz over the whole default repertoire, and the repertoire proof over every fixture, surfaced two
things the plan had not seen. Typst keeps a line's trailing spaces in the text run at zero advance and shrinks
spaces on overfull lines; the runtimes already did both, so the shaping check had to allow a narrower space. And
the middle dot (U+00B7) is CJK centre-aligned punctuation to Typst (`shaping.rs`,
`is_cjk_center_aligned_punctuation`): on an overfull line it shrinks by a quarter on each side, and it counts as
justifiable. The runtimes shrink spaces only, so a middle dot on a tight line was a silent mismatch. It is refused
now (G51); the port is about fifteen lines per runtime.

## Verification

| Check | Result |
|---|---|
| Repertoire proof on every fixture | passes; 816 characters per default-repertoire slot, 1144 for `charset` |
| `wrapfuzz`, random texts of the whole default repertoire | both runtimes identical to Typst in glyphs and pixels |

## Covered and open

Covered: `GAPS.md` G4, G9, G13, G19, G20, G44, G45, G46, G47, G49 are refusals now, G48 and G50 are closed, G15 is
fixed, G51 (the middle dot) is new and refused. Open and small: the soft-hyphen dash (G44: the data producer
hyphenates, the runtime appends Typst's `-` at a line ending on U+00AD) and the middle dot's shrinkability (G51).
Then M11, justified wrapping slots, whose plan is in `PLAN.md`.

## How to run

```sh
cd experiments/paramdoc
./check.sh                                   # the whole proof
cargo run -p paramdoc-export -- fixtures/charset --fuzz 40 --fuzz-references 20 --reference fixtures/charset/data.json
cargo run -p paramdoc-export -- fixtures/charsetbad --fuzz 1   # must exit 1, naming the Arabic letter
cargo run -p paramdoc-runtime -- ../../.build/paramdoc/figures --data fixtures/figures/data-exif-error.json --out /tmp/x.pdf   # must exit 1
```
