# Test fonts

Unmodified `LibertinusSerif-Regular.otf` and `LibertinusSerif-Bold.otf` from the crates.io source archive `typst-assets@0.15.1`, `files/fonts/`.

These are development fixtures and are not included in the core npm package or embedded in the WASM build. Applications supply their own font bytes. The copyright and SIL Open Font License for these fonts are preserved in `NOTICE.typst-assets` (the source archive's notice also describes its other assets).

`LibertinusSerif-Italic.otf` and `LibertinusSerif-BoldItalic.otf` were added for `examples/pretext-hybrid` from the official Libertinus v7.051 release (<https://github.com/alerque/libertinus/releases/tag/v7.051>, `static/OTF/`, unmodified, SIL Open Font License 1.1). The release's Regular and Bold files are byte-identical to the ones above.
